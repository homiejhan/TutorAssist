          Library

          Textbooks are the agent's source of truth. Upload PDFs here; each one gets indexed once so the agent can search it cheaply, and gets a short key (like Holt-A1) the first time it's cited.

          Default book per subject

          When a topic is in several books, the agent uses the first book in the row that covers it. A student's own textbook field overrides this.

          Book keys

          Keys are permanent once a roster entry cites them — fix titles freely, but don't rename keys.

          Open questions

          Proposals the agent made that are waiting on your call. Answer one and the agent updates the roster or spec, then removes it.
